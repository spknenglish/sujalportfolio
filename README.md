# Sujal File Studio

A responsive blue-and-white file utility dashboard branded for Sujal Wagholikar.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open `http://127.0.0.1:5173`.

## Included

- Local image compression and JPG/PNG/WebP conversion
- Images to PDF
- PDF merge, split, and rotation
- PeerJS direct file sharing
- PeerJS video room interface
- Dedicated cards and workflows for PDF/Office conversions, PDF compression, editing, trimming, password protection, and unlocking
- Live percentage progress, download states, search, categories, favorites, dark mode, and responsive hamburger navigation

Office conversions, PDF encryption/decryption, deep PDF editing, and production compression are represented by integration-ready interfaces because they require a secure server-side processing engine. The UI labels these states clearly and never pretends a file was converted.
